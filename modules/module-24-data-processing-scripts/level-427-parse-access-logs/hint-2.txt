awk -F'"' makes `"` the field separator. A normal combined line has six quotes, so NF is 7. Then split the interesting pieces again on spaces:

  echo 'a b "GET /x HTTP/1.1" 200 5' | awk -F'"' '{
    n = split($2, req, " ")        # req[1]=GET req[2]=/x req[3]=HTTP/1.1
    split($3, rest, " ")           # rest[1]=200 rest[2]=5
    print req[1], req[2], rest[1]
  }'

split returns the number of pieces, which is how you validate the shape. For the timestamp, field 4 of the first piece looks like `[04/Mar/2026:10:15:02`; `substr(x, 2)` drops the bracket. Diagnostics: `printf "..." > "/dev/stderr"`. Ternary for bytes: `(b == "-") ? 0 : b`.
