awk compares two strings alphabetically when at least one of them is not a number, and a timestamp like `2026-03-04T14:00:00Z` never looks like a number:

  awk -v lo="2026-03-04" -v hi="2026-03-05" '$1 >= lo && $1 < hi' file

A shorter bound works because "2026-03-04" is a prefix of every timestamp on that day, so it sorts before all of them and after the day before. In bash, `[[ $a > $b ]]` also compares as text. Check the shape of a field with a regex using fixed digit counts: `/^[0-9][0-9][0-9][0-9]-.../` (extended `{4}` repeats are not available in every awk). Diagnostics go to /dev/stderr with the line number NR.
