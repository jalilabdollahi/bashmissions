Ask yourself what the script needs to remember between one line and the next. For a running total the answer is: one number, plus a couple of counters. If that is all you keep, the script works the same on ten lines and on ten billion, and it can print each result immediately instead of waiting for the end.

For the money: floating point cannot represent 0.07 exactly. Cents are whole numbers, so work in cents and only insert the decimal point when printing.
