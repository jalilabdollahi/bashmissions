awk joins several subscripts into one key, so an array can have two "dimensions":

  awk -F, '{ cell[$1, $2] += $3; rowsum[$1] += $3 } END { print cell["a", "x"] + 0 }' file

(`+ 0` makes a never-seen cell print 0 instead of nothing.) Keep ordered lists of distinct names: `if (!($1 in seen)) { seen[$1] = 1; names[++n] = $1 }`. To sort names[1..n] yourself, use insertion sort:

  function isort(a, n,    i, j, t) {
    for (i = 2; i <= n; i++) { t = a[i]
      for (j = i - 1; j >= 1 && a[j] "" > t ""; j--) a[j + 1] = a[j]
      a[j + 1] = t }
  }

(Appending `""` forces text comparison even for names like 10 and 9.) Build each output line in a variable and add `,` before every cell.
