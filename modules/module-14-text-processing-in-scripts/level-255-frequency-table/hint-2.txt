The classic tally pipeline:

  cut -d' ' -f1 file | sort | uniq -c | sort -rn

uniq -c prefixes each distinct line with its count, but pads the number with leading spaces (a different amount on macOS and Linux). Remove them with:

  sed 's/^ *//'

For a tie-break, give the last sort two keys: -k1,1nr (count, numeric, reversed) then -k2,2 (the value, alphabetical).
