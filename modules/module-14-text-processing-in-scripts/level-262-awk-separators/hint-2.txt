Input separator: the -F option. Output separator: the variable OFS, which you can set on the command line with -v.

  awk -F: '{ print $1 }' /etc/passwd                 # read colon-separated
  awk -F, -v OFS=';' '{ print $1, $3 }' data.csv     # read commas, write semicolons

OFS is only inserted where print has a comma between its arguments. Quote a separator that the shell cares about: -F';'
