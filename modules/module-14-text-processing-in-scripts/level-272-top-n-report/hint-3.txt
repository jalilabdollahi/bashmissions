The finished shape:

  echo "Top $2 NXDOMAIN names"
  awk '$4 == "NXDOMAIN" { print $3 }' "$1" |
    sort | uniq -c | sed 's/^ *//' |
    sort -k1,1nr -k2,2 |
    head -n "$2" |
    awk '{ printf "%d. %s (%d)\n", NR, $2, $1 }'

After uniq -c and the sed, each line is "<count> <name>", so in the last awk $1 is the count and $2 the name.
