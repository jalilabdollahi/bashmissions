find permission tests:
  find "$root" -type f -perm -0002          # others can write (ALL listed bits must be set)
  find "$root" -type f \( -perm -4000 -o -perm -2000 \)        # setuid or setgid
-perm -MODE needs every bit of MODE. "Any of group/other bits" is therefore a list of single-bit tests joined with -o:
  \( -perm -0040 -o -perm -0020 -o -perm -0010 -o -perm -0004 -o -perm -0002 -o -perm -0001 \)
Combine name tests the same way:  \( -name '*.key' -o -name id_rsa \)

Feed a loop without a subshell, so your findings array survives:  while read -r f; do ...; done < <(find ...)

sshd semantics: lower-case the key (${key,,}), skip it if you have seen it before, store the lower-cased value in an associative array.
Credential lines: lower-case the line, match a regex with a capture group for the value, then ignore empty, "" / '', and values starting with $ or <.
