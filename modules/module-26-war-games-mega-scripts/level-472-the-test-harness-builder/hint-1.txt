Think of the runner as three layers. A discovery layer that reads each file as text and extracts the names of the test functions. An execution layer that runs one test at a time in a throw-away subshell and turns "what happened" into PASS, FAIL or SKIP using only an exit status and a message file. And a reporting layer that prints lines and counts. The assertions are plain functions that the subshell inherits from the runner. Start with the execution layer, because the subtle part is there: how a failure inside the subshell becomes information outside it.
