Randomness is the enemy of replay, so remove it: write a tiny pseudo-random generator whose next number depends only on the previous one, start it from the seed, and every run with that seed will make identical choices. Then the monkey is an ordinary loop: for each round, draw a number to decide whether to strike, draw again to choose the victim and the kind of fault. The order and the number of draws matter, because a single extra or missing draw shifts every later round. A dry-run mode that runs the same draws but only prints is the best test tool you will have.
