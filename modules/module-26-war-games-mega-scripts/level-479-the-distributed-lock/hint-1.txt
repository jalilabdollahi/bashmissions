Think of mkdir as a race you can only win once: the first caller creates the directory and gets the lock, everybody else gets an error. Everything else is bookkeeping around that moment: who won (a file inside), until when (another file), and what to do when the winner has vanished (compare the stored deadline with the NOW you were given). Write one function per command and keep "read the holder" in its own helper, because acquire, release and status all need it.
