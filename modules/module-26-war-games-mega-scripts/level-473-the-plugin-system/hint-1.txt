Separate knowing from doing. Discovery only reads headers, so a broken or malicious plugin cannot run anything just by being in the directory. Ordering is a small graph problem: repeatedly pick a plugin whose requirements are all already placed, choosing the lowest priority number (then name) when several are ready; whatever can never be picked is stuck in a cycle. Status is then decided in that order, so every plugin can look at the verdicts of the ones it needs. Only the `run` command actually executes plugin code, and each plugin does so in its own subshell.
