Ask openssl the right question and let it do the date arithmetic: `-checkend SECONDS` answers "will this certificate still be valid that many seconds from now?" with its exit status. Classify each certificate by asking it with 0, crit-days and warn-days worth of seconds. Be careful with the order of questions: openssl also exits 1 for a file that is not a certificate at all, so first make sure `-enddate` works. Collect the table rows while you loop and print once at the end, so the one-time reload can come after the table.
