grid[$r,$c]=value works because the subscript of an associative array is just a string: the shell expands $r and $c, producing a key like 2,3. read -r -a cells splits one input line into the array cells. To print the flipped grid, loop over columns on the outside and rows on the inside, and add cells to a line with line+="${line:+ }${grid[$r,$c]}" so that a space goes only between cells.
