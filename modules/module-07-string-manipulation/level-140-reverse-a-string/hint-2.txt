Positions in a string of length N run from 0 to N-1. A C-style loop can count downwards, and ${var:i:1} is the one character at position i (arithmetic works inside the offset, no $ needed for i):

  word="abc"
  for (( i = ${#word} - 1; i >= 0; i-- )); do
    echo "${word:i:1}"       # prints c, then b, then a
  done
