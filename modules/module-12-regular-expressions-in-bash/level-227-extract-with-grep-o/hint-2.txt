The -o option prints each match on its own line instead of the whole line:

  grep -oE '[a-z]+@[a-z.]+' mails.txt         # only the matched text
  grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' f    # a repeated group: "n." three times, then n

Then sort -u removes repeats. With set -o pipefail, a grep that finds nothing (status 1) fails the pipe, so guard it: { grep ... || true; } | sort -u
