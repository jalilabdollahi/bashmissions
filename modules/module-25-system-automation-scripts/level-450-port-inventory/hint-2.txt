`nc -z -w 1 host port` exits 0 when the port accepts a connection (add `2>/dev/null` to hide errors; use it directly as an `if` condition). An associative array `declare -A expected` can hold `expected[$host]=" 22 80 443 "`; padding with spaces lets you test `[[ $list == *" $port "* ]]` without 80 matching inside 8080. `${expected[$host]:-${expected[default]:-" "}}` falls back to the default line, then to nothing. Build the comma list with `open_list+=${open_list:+,}$port`, and show `-` with `${open_list:--}`.
