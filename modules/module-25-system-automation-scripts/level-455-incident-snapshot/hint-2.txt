`mkdir -m 700 DIR` creates a private folder in one step. For each remote command run `ssh -n -o BatchMode=yes "$host" "df -P" > "$file" 2>&1 || rc=$?` with `rc=0` set before it, so `set -e` does not stop you. A small function `collect FILE COMMAND...` (use `shift` and `"$*"`) keeps the four calls to one line each. ssh exits 255 only when the connection itself failed. `( cd "$dir" && cksum a b c | sort -k3,3 > MANIFEST )` computes checksums with bare names.
