Inside `while read -r host; do ... done < hostfile` the loop's stdin IS the file, and a plain `ssh` will slurp the remaining lines. `ssh -n` (or `< /dev/null`) prevents that. `-o BatchMode=yes` turns off password prompts. Capture output and status together: `rc=0; out=$(ssh -n ... "$host" "$*" 2>&1) || rc=$?`. ssh itself exits 255 when it could not connect; otherwise it returns the remote command's status. Prefix each line with `while read -r line; do echo "$host: $line"; done <<< "$out"`.
