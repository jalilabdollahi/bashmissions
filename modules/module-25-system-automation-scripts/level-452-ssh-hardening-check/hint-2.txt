An associative array can hold the table: only store a keyword if it is not set yet (`[[ -n ${seen[$key]+set} ]]` tests "is this key present", even if the value is empty). Lowercase with `${key,,}`. To accept `Key=value`, replace `=` with a space first: `line=${line//=/ }`, then `read -r key value _ <<< "$line"`. `break` out of the loop at `match`. A default is `${seen[key]:-default}`, but you also need to know whether the default was used, so test presence separately.
