Read the hosts into an array (`hosts+=("$line")`) and iterate with `for i in "${!hosts[@]}"`; then the hosts after index i number `${#hosts[@]} - i - 1`. A small function that prints the ABORT line and calls `exit 1` keeps the two failure paths identical. `cmd || fail_function` runs the function only when `cmd` fails, which also keeps `set -e` happy. For the health check use a bounded loop (`for check in 1 2 3`) and `state=$(ssh ... is-active ...) || true`, because is-active exits non-zero while the unit is not active.
