`declare -A installed` makes an associative array: `installed[$name]=$version`, and `${installed[$name]:-}` is empty when the key is missing. Fill it with `while read -r name version; do ...; done < <(dpkg-query -W -f='${Package} ${Version}\n')`. To compare `3.0.9` and `3.0.13`, split both on dots into arrays (`local IFS=.; a=($1)`) and compare element by element with `(( ))`; use `10#` so leading zeros are not octal. The leading numeric part of a version is `[[ $v =~ ^[0-9][0-9.]* ]]` then `${BASH_REMATCH[0]}`.
