Build the find tests in an array so optional ones can be added: `args=(-type f -name "$pat")`, then `(( days > 0 )) && args+=(-mtime +"$days")` and similarly `-size +"$bytes"c`. Run `find "$dir" "${args[@]}" | sort`. Quote `"$pat"` so the shell does not expand `*.tmp` against the current folder; find must see the pattern itself. Split a rule with `read -r pat days bytes extra <<< "$line"`; a non-empty `extra` or an empty `bytes` means a bad rule. A file deleted by an earlier rule fails `[[ -f $path ]]`.
