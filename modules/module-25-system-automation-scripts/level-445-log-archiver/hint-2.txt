`find DIR -maxdepth 1 -type f -name '*.log' -mtime +30` lists regular files in DIR older than 30 days; pipe through `sort` and read lines with `while IFS= read -r path; do ...; done < <(find ... | sort)`. `gzip -c file > out.gz` compresses to stdout and leaves the source alone; `gzip -t out.gz` exits non-zero if the archive is damaged. Under `set -e` a failing step stops the script before the next one, so the order "compress, test, rename, remove" protects the original.
