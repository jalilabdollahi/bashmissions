`while IFS=, read -r a b c d; do ... done < file` splits each line on commas into variables. A running counter gives you line numbers. Check a pattern with `[[ $name =~ ^[a-z][a-z0-9_-]{2,15}$ ]]` (do not quote the regex). To keep `set -e` from ending the script when a command fails, test it directly: `if useradd ...; then ... else ... fi`. The Windows `\r` can be removed from the last field with `${shell%$'\r'}`.
