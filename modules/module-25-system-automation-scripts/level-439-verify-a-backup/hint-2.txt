`read -r crc size name` splits a line into three variables (the last one takes the rest of the line). `cksum < file` prints `CRC SIZE` for stdin, while `cksum file` would add the file name. Compare as one string: `[[ $(cksum < "$f") == "$crc $size" ]]`. For the unlisted pass, loop over `"$dir"/*` and check each name against what you remembered from the manifest (a string of names, or an associative array).
