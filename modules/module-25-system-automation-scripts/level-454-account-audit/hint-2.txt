`IFS=: read -r name pw uid gid gecos home shell <<< "$line"` splits a passwd line. Count fields by counting colons: `colons=${line//[^:]/}` leaves only the colons, so `${#colons}` must be 6. Use `declare -A hash` for shadow (`hash[$name]=$pw`); `${hash[$name]+set}` tells "has an entry" from "has an empty hash". For shared UIDs keep `uid_names[$uid]+=" $name"` and a separate array remembering the order UIDs first appeared. `${shell##*/}` is the shell's file name, ready for a `case`.
