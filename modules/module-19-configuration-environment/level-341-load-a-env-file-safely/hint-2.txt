`while IFS= read -r line` gives you each line untouched. A regex in `[[ ... =~ ... ]]` can split it, and the pieces land in the BASH_REMATCH array:

  if [[ $row =~ ^([a-z]+)=(.*)$ ]]; then
    name=${BASH_REMATCH[1]}; rest=${BASH_REMATCH[2]}
  fi

`export "$name=$rest"` stores the text without evaluating it. Trim with `${v#"${v%%[![:space:]]*}"}`.
