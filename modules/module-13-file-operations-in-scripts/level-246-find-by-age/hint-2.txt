`find DIR -type f -mtime +30` lists files last modified more than 30 days ago. `find DIR -type f -newer REF` lists files modified more recently than the file REF. Skip one particular file by name with `! -name`:

  find "$dir" -type f ! -name .marker -mtime +"$n"
  find "$dir" -type f -newer "$dir/.marker"

Reading lines from a variable one at a time: `while IFS= read -r p; do ...; done <<< "$list"`.
